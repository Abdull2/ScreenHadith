مِشكاة v0.7 — إصدار التحقق وتجربة العرض

ارفع كل الملفات الموجودة هنا مباشرة إلى Root مستودع GitHub Pages.

مهم:
- v0.7 يعرض رياض الصالحين: 1896 سجلًا، مع بقاء ملف riyad.json نفسه دون تعديل عن النسخة المعتمدة.
- قبل إتاحة زر بدء العرض، يتحقق التطبيق من SHA-256 لملف riyad.json ثم يفحص اكتمال الأرقام 1..1896 وعدم وجود سجل فارغ أو مكرر.
- النص المعروض لا يُختصر ولا يُعاد صياغته. الأحاديث الطويلة تُقسَّم إلى أجزاء متتابعة بقطع متصل من النص، ومجموع الأجزاء يساوي النص الأصلي حرفيًا.
- تقسيم الأحاديث أصبح يراعي عرض الشاشة وارتفاعها، مع فحص إضافي لمساحة النص بعد الرسم.
- بطاقة المصدر على شاشة العرض مختصرة، بينما نافذة «المصدر والتحقق» تفصل بين ملف النص المعتمد وبين المراجع الخارجية للمقارنة.
- روابط Sunnah.com والشاملة مراجع للمقارنة والتحقق، ولا تدّعي الواجهة أن النص منقول حرفيًا منها.
- ملء الشاشة لا يُطلب تلقائيًا في kiosk؛ يظهر فقط عندما يدعمه المتصفح ويحتاج إلى إجراء من المستخدم عند اللزوم.
- الإعدادات القديمة من v0.6 تُقرأ تلقائيًا ثم تُحفظ بالمفتاح الجديد.
- Service Worker يستخدم Cache باسم v0.7، ويحذف Cache إصدارات مِشكاة القديمة بعد التفعيل. عند وجود تحديث لاحق يظهر خيار «تحديث الآن».
- عند فتح الإعدادات أو نافذة المصدر، يتوقف توقيت الانتقال مؤقتًا ثم يستأنف بعد الإغلاق إذا كان العرض يعمل قبل الفتح.
- لا توجد عبارة دينية ثابتة يحقنها Runtime UI داخل مساحة نص الحديث.

بعد أول رفع فوق v0.6:
- افتح مرة واحدة مع ?v=7 إذا كان المتصفح يعرض نسخة قديمة جدًا من الصفحة بسبب Cache سابق، ثم استخدم الموقع طبيعيًا بعد ذلك.
