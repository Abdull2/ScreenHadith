مِشكاة | شاشة الحديث — v0.4

نسخة GitHub Pages مصممة لتعمل وكل الملفات في الـroot فقط.
لا توجد Google Fonts أو أي CSS/JS خارجي مطلوب لفتح الشاشة.

الرفع:
1) فك ملف ZIP.
2) ارفع كل الملفات الظاهرة مباشرة إلى Root المستودع.
3) GitHub > Settings > Pages > Deploy from a branch > main > /root.
4) بعد النشر افتح الرابط مرة واحدة بالإنترنت حتى يكتمل Cache الـPWA.

أمثلة تشغيل كيوسك:
?autostart=1&controls=0
?kiosk=1&duration=30&sources=riyad,nawawi&theme=auto&length=620

ملاحظة Fullscreen:
المتصفحات العادية قد تمنع الدخول التلقائي إلى Fullscreen بدون لمسة من المستخدم. عند تثبيت الـPWA، manifest مضبوط على fullscreen. في المتصفح استخدم زر «ابدأ بملء الشاشة» أو F/F11 حسب الجهاز.

المصادر:
- الأربعون النووية: بيانات تدارك المراجعة، مع رابط النص على Sunnah.com ورابط شرح مرجعي حيث يتوفر.
- رياض الصالحين: 1896 سجلًا. تمت معالجة نسخة العرض لفصل الراوي/السند عن المتن والتخريج، مع رابط مرجع النص على Sunnah.com حسب رقم الحديث.
- مختارات المتفق عليه: 12 مختارًا مراجعًا، مع أرقام البخاري/مسلم حيث كانت محفوظة في بيانات تدارك وروابط الدرر السنية.

توليد بيانات العرض:
build_display_data.py يحول ملفات المصدر إلى:
- nawawi-display.json
