مِشكاة | شاشة الحديث — نسخة GitHub Pages مسطحة

كل الملفات في هذا المجلد موجودة في الـROOT مباشرة، ولا تحتاج إنشاء أي فولدرات.

طريقة الرفع:
1) أنشئ Repository جديد على GitHub.
2) Add file -> Upload files.
3) اسحب كل الملفات الموجودة هنا مرة واحدة إلى الريبو.
4) Commit changes.
5) Settings -> Pages.
6) Source: Deploy from a branch.
7) Branch: main / root ثم Save.

بعد ظهور رابط Pages افتحه واضغط «ابدأ بملء الشاشة».

الهوية: «مِشكاة» بألوان كحلي/مرجاني/بنفسجي فاتح ولوجو مستقل.
